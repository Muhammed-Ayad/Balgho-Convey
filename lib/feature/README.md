# Feature Packages

## Overview
Houses self-contained clean architecture domain features following the strict modular layout: `logic/` (models, providers, repositories) and `view/` (screens, widgets).

## Subdirectories & Boundaries
- `azan`: [./azan/README.md](./azan/README.md) - Astronomical prayer time calculations, countdowns, and Hijri calendar conversions.
- `azkar`: [./azkar/README.md](./azkar/README.md) - Supplications catalog (Hisn al-Muslim) with interactive counters and filter chips.
- `contact_us`: [./contact_us/README.md](./contact_us/README.md) - Support information, developer email actions, and store redirection.
- `daily_zekr`: [./daily_zekr/README.md](./daily_zekr/README.md) - Calendar-date rotated daily supplications and Hadiths.
- `favorites`: [./favorites/README.md](./favorites/README.md) - Unified cross-feature bookmarking and persistence.
- `habits`: [./habits/README.md](./habits/README.md) - Daily worship and Sunan prayer completion checklist with streak tracking.
- `home`: [./home/README.md](./home/README.md) - Primary application dashboard, upcoming prayer countdown, and widget tutorial.
- `nawawi`: [./nawawi/README.md](./nawawi/README.md) - Forty Hadith of Imam al-Nawawi with comprehensive Arabic explanations.
- `notifications`: [./notifications/README.md](./notifications/README.md) - System notification channel toggles, diagnostic inspector, and alarm controls.
- `prophet`: [./prophet/README.md](./prophet/README.md) - Prophetic characteristics, morals, and biography topics.
- `qibla`: [./qibla/README.md](./qibla/README.md) - Kaaba direction bearing and magnetometer compass dial.
- `quran`: [./quran/README.md](./quran/README.md) - Noble Quran reader in Uthmanic Hafs font with bookmarking and search.
- `radios`: [./radios/README.md](./radios/README.md) - Online Islamic radio streams with background audio handler and media notifications.
- `settings`: [./settings/README.md](./settings/README.md) - Adhan voice reciters, daylight saving modes, and application theme preferences.
- `tasbih`: [./tasbih/README.md](./tasbih/README.md) - Digital tasbih counter with vibration feedback and customizable goals.
