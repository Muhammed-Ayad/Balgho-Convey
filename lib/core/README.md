# Core Infrastructure

## Overview
Houses system-wide architectural foundations, cross-cutting services, network clients, navigation routing, styling tokens, and reusable UI components.

## Subdirectories & Boundaries
- `assets`: [./assets/README.md](./assets/README.md) - Static asset path constants and image references.
- `helpers`: [./helpers/README.md](./helpers/README.md) - Context extensions, constants, and UI execution helpers.
- `network`: [./network/README.md](./network/README.md) - Dio HTTP client, endpoint definitions, and network exception mappers.
- `routes`: [./routes/README.md](./routes/README.md) - GoRouter route table and screen navigation transitions.
- `services`: [./services/README.md](./services/README.md) - Hardware sensors, local notifications, audio caching, and native AppWidget synchronization.
- `theme`: [./theme/README.md](./theme/README.md) - Colors, typography, theme data, and theme mode Riverpod state notifier.
- `widgets`: [./widgets/README.md](./widgets/README.md) - Reusable design system widgets (app bar, loading, error, empty state).
