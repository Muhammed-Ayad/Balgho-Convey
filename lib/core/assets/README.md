# Core Assets Package

## Overview
Centralizes static asset path constants, including raster images and vector icons utilized across the application.

## Interface
- `[lib/core/assets/assets_manager.dart:imagePath]` - Base path for image assets (`assets/images`).
- `[lib/core/assets/assets_manager.dart:ImageAssets]` - Container class for static image asset path references (`radio`, `azkar`, `prayer`, `kabaa`, `nawawi`).
